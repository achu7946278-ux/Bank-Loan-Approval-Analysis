# 🏦 Loan Approval Analysis Using Power BI

## 📌 Project Overview
This project focuses on analysing loan application data to understand loan approval and rejection patterns. An interactive Power BI dashboard was developed to explore applicant information and identify factors associated with loan approval outcomes.

## 🎯 Project Objectives
- Analyse loan approval and rejection rates.
- Understand the relationship between credit scores and loan approval.
- Explore approval patterns across different age groups.
- Examine loan applications based on employment status.
- Present key insights through an interactive dashboard.

## 🛠️ Tools & Technologies
- Power BI
- Data Cleaning and Transformation
- Data Visualisation
- DAX

## 📊 Key Performance Indicators (KPIs)
- Total Loan Applications
- Loan Approval Rate
- Loan Rejection Rate
- Average Loan Amount

## 🔍 Key Insights
- **72.9% Approval Rate:** 729 out of 1,000 loan applications were approved.
- **27.1% Rejection Rate:** 271 out of 1,000 applications were rejected.
- **Credit Score:** Approved applicants had an average credit score of 609.49, compared with 486.37 for rejected applicants.
- **Age Group Analysis:** Applicants aged 26–35 showed a relatively high approval rate.
- **Employment Analysis:** Self-employed applicants formed the largest applicant group, with 350 applications.

## 📈 Dashboard Features
- Overview of loan approval and rejection rates.
- Average loan amount analysis.
- Credit score comparison between approved and rejected applicants.
- Age group analysis.
- Employment status analysis.
